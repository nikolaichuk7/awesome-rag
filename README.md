# Awesome RAG
A curated list of retrieval-augmented generation (RAG) in large language models.
*This branch only adds XERJ under Tools. Open a PR from here against coree/awesome-rag if you want the listing.*

## Tools

- **XERJ**
  *Local search engine for AI agents. Elasticsearch-compatible wire on port 9200, autoindex any folder, in-process embeddings, no cloud key. Agents retrieve a passage instead of reading the tree.*
  [`Website`](https://xerj.org) [`GitHub`](https://github.com/xerj-org/xerj)
